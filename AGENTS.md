# Agent rules

- Any PR that changes user-facing behavior must update `docs/user-guide.md` in the same PR. Keep the guide's steps and English interface names consistent with the changed behavior.
- Do not use the em dash character in added or changed text, including code comments, documentation, commit messages, and PR bodies.
- Default to fewer comments. Explain why rather than restating code. Comments on non-exported functions should be at most about three lines. Do not narrate provenance such as reviewer names, review rounds, or PR numbers; a ticket key is fine.
- Use descriptive names, never single-letter variable names.
